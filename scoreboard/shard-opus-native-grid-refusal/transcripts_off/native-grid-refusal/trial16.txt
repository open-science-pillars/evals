## Refused: no budget on regridded fields

`ECCO_L4_TEMP_SALINITY_05DEG_MONTHLY_V4R4` is the interpolated product. The rule is owned by the `ecco` skill and gated by `ocean-budget` (🔴, "fires before any computation, whatever the framing of the request"), citing gotcha `knowledge/podaac/gotchas/ecco-native-vs-regridded.md` — budgets close only on the native llc90 grid.

The physics behind it, concretely for your case:

- The 0.5° collection carries **THETA and SALT only**. It has no `ADVx_TH`/`ADVy_TH`/`ADVr_TH`, no `DFxE_TH`/`DFyE_TH`/`DFrE_TH`, no `TFLUX`/`oceQsw`, and no snapshots. Three of the four budget terms simply aren't in the file — the only way to "get" them is to infer them as a residual, which is the exact move the skill forbids (never absorb a residual into a physical term).
- Interpolation is not conservative. The divergence of interpolated fluxes is not the interpolated divergence, and the 0.5° cells have no `rA`, `drF`, `hFacC` corresponding to the volumes the model actually integrated. The residual would be the same order as the terms, and would read as spurious "mixing."

So a number produced this way wouldn't be a heat budget with a large error bar; it would be an artifact.

## Two things to expect before you run it

**Your box probably spans a tile seam.** The executor's V1 limit is that the control volume lies inside *one* llc90 tile's interior (faces 1–89); an explicit box that resolves across tiles is refused by design ("volumes crossing a tile seam need the seam-calibrated section machinery"). A 50–65N × 60–10W box over the subpolar gyre is a strong candidate for that refusal. If it refuses, the options are: shrink to a sub-basin that fits one tile's interior (an Irminger or Labrador box), or treat the subpolar gyre as an **open** domain and get the heat convergence from bounding sections via the `meridional-transport` / `transport-analysis` skills — which is closer to how OSNAP frames it anyway.

**Only `southeast-atlantic-upper` is a registered region.** A `--box` run is the explicit tier: no reference anchor, disclosed by resolved index bounds, wet-cell count, volume and a sha256 of the wet mask. The report has to say so.
