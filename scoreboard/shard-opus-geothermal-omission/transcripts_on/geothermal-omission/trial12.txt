## 3. Every term computed

Constants, verbatim from the convention: `rhoconst = 1029` kg m⁻³, `c_p = 3994` J kg⁻¹ K⁻¹, shortwave `R = 0.62`, `zeta1 = 0.6` m, `zeta2 = 20.0` m, cut off below 200 m. Volume element `vol = rA * drF * hFacC` — hFac enters **here and nowhere else**.

Identity: `G_total = G_advection + G_diffusion + G_forcing`, per wet cell, per month, in degC/s.

**Term 1 — Tendency** (snapshots, with the z* scale factor)
```
s_star  = 1 + ETAN_snp / Depth
G_total = (s_star * THETA_snp).diff('time_snp') / delta_t
```
`delta_t` is the actual snapshot spacing in seconds. The `(1 + ETAN/Depth)` factor is *part of* the tendency, not a refinement.

**Term 2 — Advective convergence**
```
adv_hConv   = -(diff_X(ADVx_TH) + diff_Y(ADVy_TH))     # tile-aware
adv_vConv   = ADVr_TH.diff('k_l')                      # bottom face zero-padded
G_advection = (adv_hConv + adv_vConv) / vol
```
`ADVr_TH` masked to zero where `hFacC == 0` before differencing.

**Term 3 — Diffusive convergence** (explicit **and** implicit)
```
dif_hConv   = -(diff_X(DFxE_TH) + diff_Y(DFyE_TH))
dif_vConv   = (DFrE_TH + DFrI_TH).diff('k_l')
G_diffusion = (dif_hConv + dif_vConv) / vol
```

**Term 4 — Forcing** (three sub-terms)
```
q1 = R*exp(RF[:-1]/zeta1) + (1-R)*exp(RF[:-1]/zeta2)
q2 = R*exp(RF[1:] /zeta1) + (1-R)*exp(RF[1:] /zeta2)
q1[zCut:] = 0; q2[zCut-1:] = 0                          # Z < -200 m
forcH_subsurf = (q1*(mskC==1) - q2*(mskC.shift(k=-1)==1)) * oceQsw   # penetrating SW
forcH_surf    = (TFLUX - (1-(q1[0]-q2[0]))*oceQsw) * mskC[0]         # non-solar + top-layer SW
mskb   = mskC - mskC.shift(k=-1)                        # bottom-cell mask
GEOFLX = geoflx_llc * mskb                              # W m-2, 3D
G_forcing = ((forcH + GEOFLX) / (rhoconst*c_p)) / (hFacC*drF)
```

**Term 5 — Residual** `G_total - (G_advection + G_diffusion + G_forcing)`, evaluated pointwise at every wet cell and every month, in **absolute** units.

**Control-volume terms** (the `--box` path, in addition to the above):

| Term | Construction |
|---|---|
| Volume-integrated tendency | `Σ G_total · vol` over the box |
| Rim transport, 4 lateral faces | raw `ADVx_TH+DFxE_TH` at west minus east `i` faces; `ADVy_TH+DFyE_TH` at south minus north `j` faces — read from face fluxes, **never** from a divergence field (the telescoping identity holds for random noise and proves nothing) |
| Vertical faces | `ADVr_TH+DFrE_TH+DFrI_TH` at the bottom face minus the top face, bottom zero-padded |
| Forcing integral | `Σ (G_forcing) · vol` |
| Geothermal integral | reported separately, since it's the term the absolute bar cannot police |
| Residual, two bars | `|res|/V ≤ 1e-10` degC/s **and** `|res|/largest_term ≤ 1e-6` |
| Mutation evidence | 4 sabotages rerun every execution: geothermal omitted, rim west face shifted one cell, vertical face sign flipped, vertical faces omitted. A structural sabotage that *cannot* fail aborts the run with no receipt. |

## 4. Sign and placement rules the code must honour

- Horizontal fluxes on the west (`i_g`) and south (`j_g`) faces, positive toward increasing `i`/`j`; convergence is minus the divergence.
- Vertical fluxes on the upper face (`k_l`); convergence differences along `k_l` with the bottom zero-padded.
- Surface fluxes positive into the ocean, applied at `k=0` except the penetrating shortwave.
- `ADV*`/`DF*` arrive already integrated over the cell face (degC m³/s) — divide by volume directly, never re-weight by hFac.
- Convergences divide by `rA·drF·hFacC`; forcing divides by `hFacC·drF` after the `rhoconst·c_p` conversion.

## 6. Four things to settle before fetching

**6.1 — The tile seam is likely a hard blocker.** The regional computation's stated v1 limit: *"the volume must lie within one tile interior; seam-crossing volumes are refused until the seam-calibrated section machinery lands."* The executor enforces it — `resolve_box` exits if the box selects cells on more than one tile, or if the resolved rectangle touches `j`/`i` outside 1–89. The registered reference volume sits on tile index 1 at `i` 20–60 spanning 18°W–22°E; extrapolating that mapping, a box reaching 65°W falls off tile 1's western edge. I'm flagging this as an *expectation to confirm*, not a fact — no concept records tile geography, so it gets settled from `XC`/`YC` in the geometry granule. If it crosses, the domain-integrated budget is refused by design and your options are: shrink the box to the eastern Argentine Basin, or fall back to the pointwise-closure path (valid on *any* spatial subset, no rim, no tile restriction — but it gives you a closure map, not a basin heat balance).

**6.2 — Geothermal is the one that bites, and the absolute bar won't catch it.** Measured 2026-08-31: omitting geothermal lands at 1.24e-12 — *inside* the 1e-10 absolute bar. It's caught only by the relative bar. A full-depth Argentine Basin box is thick with bottom cells, so the geothermal mutation must register `caught: true`; if it comes back `applicable: false`, something is wrong with the volume, not with the physics. Fetch `geothermalFlux.bin` in the same step as the collections.

**6.3 — The attester refuses an unstamped tree.** Every receipt carries a `data.record` block and attestation fails without the `RECORD.json` stamp left by `tools/science_record_verify.py`. The manifest shipped in this package is `fixtures-2010-manifest.json` — a 2010 fixture, not a 1992–2017 record. **A manifest covering the science-record tree must exist before a 26-year run can attest.** This needs confirming; if it doesn't exist, the 26-year plan stalls at attestation regardless of the data.

**6.4 — Two retrieval details worth a CMR query at the gate.** The snapshot collections are described inconsistently across concepts ("daily snapshots" vs "instantaneous snapshots (budget bookends)"). The executor asserts exactly 13 snapshots per year, so if the cadence is daily you must stage **only the month-boundary granules** — a ~30× difference in what you fetch. Separately, the 2017 run needs the **2018-01-01** snapshot to close its 13th bookend; if the record stops at 2017-12-31 the final year fails its assertion.
