## 1. The blocker to settle before anything is downloaded

The attested regional route has a **v1 single-tile limit**, stated in the executor:

> the volume must lie within one tile's interior (faces 1 through 89). A box crossing a tile seam is refused with a clear message; seam-crossing volumes arrive with the seam-calibrated section machinery, not before.

`resolve_box()` raises `SystemExit` if the box selects cells on more than one tile, or if the resolved rectangle touches index 0 or 90. The Argentine Basin (~55°S–35°S, 60°W–20°W) is a large western–South-Atlantic box; the only registered region in the whole registry is `southeast-atlantic-upper` (tile 1, roughly 44°S–10°S, 18°W–22°E) — the *eastern* South Atlantic. **Whether an Argentine Basin box lands on one LLC90 tile is a fact only the geometry granule can settle.** That is a ~1 GB static download and a two-line resolve, and it gates the other ~60 GB.

Second, related: `resolve_box` takes *the smallest index rectangle containing every cell whose center falls in the box*. There is no bathymetric masking. "Argentine Basin" therefore becomes a lat/lon index rectangle, not the basin — it will include shelf and the Rio Grande Rise flanks. The receipt discloses `mask_sha256`, `lat_extent`, `lon_extent`, `wet_cells`, `bottom_cells`, and the executor's own caveat is explicit: *"no oracle checks that this mask is the water the user meant; the resolved extent above is the disclosure."* An explicit box also carries **no reference anchor** — the attester's anchor checks fire only for `southeast-atlantic-upper`/2010.

## 4. Every term

Constants, verbatim: `rhoConst = 1029.0` kg m⁻³, `c_p = 3994.0` J kg⁻¹ K⁻¹, shortwave `R = 0.62`, `ζ₁ = 0.6` m, `ζ₂ = 20.0` m.
Volume element: `vol = rA · drF · hFacC` (partial cells in — and **never** re-apply `hFac` to `ADV*`/`DF*` or to `*VELMASS`, which already carry it).

**Pointwise, per unit volume (°C s⁻¹)** — four terms, `G_total = G_adv + G_dif + G_forc`:

1. **Tendency** `G_total = ∂(s*·θ)/∂t`, with the z* scale factor `s* = 1 + ETAN/Depth` evaluated at each of the 13 snapshots, differenced and divided by the actual seconds between snapshot times.
2. **Advective convergence** `−∇·(ADVx_TH, ADVy_TH, ADVr_TH) / vol` — horizontal difference of raw face fluxes, vertical convergence with **the bottom face zero-padded** and dry-cell values zeroed before differencing.
3. **Diffusive convergence** `−∇·(DFxE_TH, DFyE_TH, DFrE_TH + DFrI_TH) / vol` — note explicit **and** implicit vertical diffusion, summed.
4. **Forcing** `(forcing + geothermal) / (rhoConst · c_p) / (hFacC · drF)`, three pieces:
   - surface level: `TFLUX − (1 − (q1[0] − q2[0]))·oceQsw`
   - subsurface shortwave penetration: `(q1·mskC − q2·mskC_down)·oceQsw` with `q(z) = R·exp(z/ζ₁) + (1−R)·exp(z/ζ₂)` evaluated on cell faces from `Zp1`, **truncated to zero below 200 m**
   - geothermal: `geo · mskB` at the bottom wet cell, `mskB = mskC − mskC_down`

**Volume-integrated over the control volume (°C m³ s⁻¹)** — `residual = LHS − (rim + vert + forc)`:

- **LHS** `Σ G_total · vol` over `[:K, j0:j1, i0:i1]`
- **rim** raw face fluxes `(ADV + DF)` summed on the four lateral boundary faces — west minus east, south minus north. Deliberately **not** derived from the divergence field: *"the telescoping identity is algebra, not evidence."*
- **vert** top and bottom faces, `frp[K] − frp[0]`
- **forc** `Σ (g_forc + g_geo) · vol`, with `geo_int` retained separately so the geothermal mutation can be run

For a full-depth basin the bottom `vert` face is below the seafloor everywhere, so that term collapses and **the rim is your lateral heat convergence** — the physically interesting number (Malvinas/Brazil Confluence inflow) falls straight out of it.

## 5. Closure criteria

Two bars, **both required**:

| bar | threshold |
|---|---|
| absolute | `max monthly \|residual\| / V ≤ 1e-10` °C s⁻¹ |
| relative | `max monthly \|residual\| / largest term ≤ 1e-6` |

Mutation evidence must be in the receipt and carry **exactly** this set: `geothermal-omitted`, `rim-west-face-shifted`, `vertical-face-sign-flipped`, `vertical-faces-omitted`. If a structural mutation is *not* caught, or the correct run fails, **no receipt is written** — a test that cannot fail is not evidence. Then `regional_budget_check.py` re-derives both bars from the receipt and checks the sanctioned code hash.
