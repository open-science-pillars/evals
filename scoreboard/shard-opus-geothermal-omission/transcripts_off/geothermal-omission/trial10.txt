## Read this first: the Argentine Basin has no attested route today

The attested regional executor (`ecco_regional_budget.py:134`, `resolve_box`) refuses any control volume that spans more than one LLC90 tile, and refuses a rectangle touching a tile edge (`1 ≤ j0`, `i1 ≤ 89`). Its stated V1 limit: *"seam-crossing volumes arrive with the seam-calibrated section machinery, not before."*

The Argentine Basin (~35–55°S, 20–65°W) straddles a **face seam**. Calibrating off the one registered region — `southeast-atlantic-upper` is tile 1, `i` 20–60 → 18°W–22°E, i.e. ~1.0° per `i` cell — tile 1's western edge sits near **38°W**. So:

- 38°W–20°W (the eastern basin, over the Mid-Atlantic Ridge flank) → tile 1, resolvable.
- 65°W–38°W (the western basin, the Brazil–Malvinas Confluence, the Argentine slope — the dynamically interesting part) → face 5 (tiles 10–12).

An explicit `--box -55 -35 -65 -20` will exit with *"explicit box spans tiles [...]; refused here by design."* The pointwise executor `ecco_heat_budget.py` doesn't help either: it registers only `tile1-interior`, and its attester hashes the file, so adding a region is not an option.

Second, softer limit: `resolve_box` returns the smallest **index rectangle** containing the box. The Argentine Basin is a bathymetric feature; a rectangle will include the Argentine shelf and ridge crest. There is no arbitrary-mask path in the attested tooling — only disclosure via `mask_sha256` and the lat/lon extent in the receipt.

## Terms to compute

Constants, carried verbatim: `rhoConst = 1029.0` kg m⁻³, `c_p = 3994.0` J kg⁻¹ K⁻¹; shortwave `R = 0.62`, `ζ₁ = 0.6` m, `ζ₂ = 20` m. Volume element `V = rA · drF · hFacC` — partial cells are **in**, and the flux variables already carry hFac, so no second application.

**Pointwise, per wet cell per month (degC s⁻¹):**

1. **Tendency** `G_total = ∂(s*·θ)/∂t`, with `s* = 1 + ETAN/Depth`, differenced across the bracketing snapshots and divided by the exact seconds between them. Not from monthly-mean THETA.
2. **Advective convergence** `G_adv = −[∇_h·(ADVx_TH, ADVy_TH) + Δ_r ADVr_TH] / V`, bottom face zero-padded.
3. **Diffusive convergence** `G_dif = −[∇_h·(DFxE_TH, DFyE_TH) + Δ_r(DFrE_TH + DFrI_TH)] / V`. Explicit and implicit vertical diffusion are summed; dropping `DFrI_TH` is the classic silent failure.
4. **Forcing** `G_forc = [(forcH + geothermal) / (ρ_c·c_p)] / (hFacC·drF)` where
   - `q(z) = R·exp(z/ζ₁) + (1−R)·exp(z/ζ₂)`, evaluated on cell faces;
   - surface level: `TFLUX − (1 − (q₁[0] − q₂[0]))·oceQsw`;
   - subsurface: `(q₁·mskC − q₂·mskC_down)·oceQsw`, forced to zero below the first level with `Z < −200` m;
   - geothermal applied at bottom wet cells only, via `mskB = mskC − mskC_down`.

Residual `= G_total − (G_adv + G_dif + G_forc)`, evaluated at every wet cell and every month, in absolute units. A relative-to-dominant-term ratio is not a closure criterion on a float32 archive.

**Control-volume integrals (degC m³ s⁻¹), which is what a basin budget reports:**

- `LHS = Σ G_total · V` over the volume.
- `Rim` = **raw face fluxes** at the four boundary faces — `(ADV+DF)_x` at `i0` minus at `i1`, `(ADV+DF)_y` at `j0` minus at `j1`. Never derived from the divergence field: the telescoping identity is algebra, not evidence.
- `Vertical` = `(ADVr + DFrE + DFrI)` at the bottom face `K` minus the surface face `0`. At full depth `K = 50` indexes the zero-padded bottom, so the only bottom-boundary input is geothermal — which is the physical point of doing this full-depth.
- `Forcing` = `Σ (G_forc + G_geo)·V`, with `geo_int` reported separately.
- `Residual = LHS − (Rim + Vertical + Forcing)`.

Because a basin box is an **open domain**, the rim and vertical transports are headline results carrying the Brazil–Malvinas convergence, not merely closure bookkeeping.

**Pass bars (both required, heat):** `max|res|/V ≤ 1e-10` degC s⁻¹ **and** `max|res|/largest_term ≤ 1e-6`.

**Mutation evidence** the executor generates and the attester checks: `geothermal-omitted`, `rim-west-face-shifted`, `vertical-face-sign-flipped`, `vertical-faces-omitted`. If a structural mutation passes, or the correct run fails, no receipt is written. At full depth I'd expect `geothermal-omitted` to be *caught* rather than marked inapplicable — that's your confirmation the depth range is doing real work.
